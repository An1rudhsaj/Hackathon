# Changelog

All notable changes to Sports Craft Engine will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of Sports Craft Engine
- Real-time player and ball tracking
- 3D pitch visualization with Three.js
- AI-powered commentary generation (8 languages)
- Multiple input sources (video upload, RTSP, simulator)
- WebSocket-based live streaming
- Team analytics and statistics
- Heat map visualization
- Passing network analysis
- Event detection (goals, shots, saves, fouls, cards)
- Expected goals (xG) calculation
- Highlight clip generation
- Meme generator for match moments
- Tactical reasoning engine
- Half-time summary generation
- HLS video preview
- Pitch calibration (manual and automatic)
- REST API with authentication
- Socket.IO real-time updates
- Configurable team colors and names
- Multi-persona commentary (tactical, hype, radio)
- Text-to-speech commentary
- Social media export features
- AR overlay support
- Multiple camera modes

### Features Breakdown

#### Core Analytics
- 25 Hz player tracking
- 10 Hz analytics updates
- Real-time possession calculation
- Distance covered tracking
- Speed measurements
- Formation detection
- Offside line visualization

#### AI Features
- Gemini-powered commentary
- Event summarization
- Tactical analysis
- Counter-attack assessment
- Performance ratings
- Multi-language support

#### Video Processing
- Multiple format support (MP4, MOV, MKV, AVI, WebM, M4V, TS)
- RTSP stream ingestion
- HLS adaptive streaming
- Automatic highlight extraction
- FFmpeg-based processing

#### Dashboard
- Interactive 3D pitch
- Real-time statistics panels
- Event timeline
- Commentary feed
- Highlight gallery
- Side-by-side video view
- Responsive controls
- Dark theme UI
